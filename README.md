# House Price Prediction

## Project Overview
This project uses Machine Learning to predict house values using the California Housing Dataset.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset
California Housing Dataset from Scikit-learn.

## Machine Learning Models
1. Linear Regression
2. Random Forest Regressor

## Model Evaluation

| Metric | Linear Regression | Random Forest |
|---|---:|---:|
| MAE | 0.5332 | 0.3277 |
| MSE | 0.5559 | 0.2560 |
| RMSE | 0.7456 | 0.5060 |
| R² Score | 0.5758 | 0.8046 |

## Best Model
Random Forest Regressor achieved an R² Score of approximately 80.46% on the test dataset.

## Saved Model
`house_price_model.pkl`

## Conclusion
Random Forest Regressor performed better than Linear Regression on the test dataset.
